# **INSTALLATION:**
## __Windows__
    1. Install python from the Python Software Foundation
    2. Install git from git-scm.com
    3. Clone the repository into your desired folder with "git clone https://github.com/Delsune/To-Do_CLI.git" in Powershell
    4. Run "python main.py" in Powershell to run the app

##  __Linux/Mac__
    1. Install python from either the Python Software Foundation (Mac), or using "sudo [package manager] -S python" (Linux distros)
    2. Install git from either git-scm.com (Mac) or "sudo [package manager] -S git" (Linux distros)
    3. Clone the repository into your desired directory with "git clone https://github.com/Delsune/To-Do_CLI.git" (or using SSH/Github CLI)
    4. Run "python main.py" in your terminal to run the app
